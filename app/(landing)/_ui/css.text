/* ============================================================
   Admin dashboard scope — Slate + Indigo/Violet.

   Re-declares the shared semantic token names (--card, --primary,
   --muted, etc.) so every existing bg-card / text-primary / border-border
   utility used throughout components/ui and components/admin resolves to
   admin colors with ZERO component changes, once this class is applied to
   AdminShell's root div. Landing pages (outside this class) keep the
   :root values untouched.

   This works because @theme inline emits utilities that reference the
   variable itself (e.g. `.bg-card { background-color: var(--card) }`),
   not a value baked in at build time — verified by compiling a probe
   stylesheet with this project's own Tailwind v4. Do NOT remove the
   `inline` keyword from the @theme block below; without it these
   utilities would resolve to a literal color at build time and this
   whole scoping mechanism would silently stop working.
   ============================================================ */

/* Thin themed scrollbar. Thumb color comes from --scrollbar-thumb, which
   is only declared inside .admin-theme (light + dark) — so this utility
   auto-themes to slate there, and falls back to a generic grey anywhere
   else it's applied. Covers Firefox + modern Chromium via
   scrollbar-color/scrollbar-width, and Safari/older Chromium via the
   ::-webkit-scrollbar pseudo-elements. */
@utility scrollbar-thin {
  scrollbar-width: thin;
  scrollbar-gutter: stable;
  scrollbar-color: var(--scrollbar-thumb, hsl(0 0% 50% / 0.4)) var(--scrollbar-track, transparent);

  &::-webkit-scrollbar {
    width: 6px;
    height: 6px;
  }
  &::-webkit-scrollbar-track {
    background: var(--scrollbar-track, transparent);
  }
  &::-webkit-scrollbar-thumb {
    background-color: var(--scrollbar-thumb, hsl(0 0% 50% / 0.4));
    border-radius: 9999px;
  }
  &::-webkit-scrollbar-thumb:hover {
    background-color: var(--scrollbar-thumb-hover, hsl(0 0% 50% / 0.6));
  }
  &::-webkit-scrollbar-corner {
    background: transparent;
  }
}
